**Fare Wave** is an intelligent, production-ready full-stack public transit application. It allows users to book tickets via a beautiful dashboard or by simply speaking to an integrated AI assistant (Rexa AI). The system utilizes mathematically verifiable Cryptographic QR codes to allow offline scanning and validation by transit conductors.

---

## 🌟 Core Features

- **🗣️ AI Voice Booking (Rexa AI):** Integrated with Google Dialogflow. Speak or type your destination (e.g., "Book a ticket from HSR to Majestic") and the AI will automatically generate your ticket.
- **🔒 Cryptographic QR Codes:** QR codes are not just random strings. They are mathematically signed JSON Web Tokens (JWTs) that embed the ticket metadata. Scanners can verify the ticket's authenticity *completely offline* without a database connection.
- **💳 Secure Digital Wallet:** Integrated with Razorpay. Wallet tops-ups are protected by server-side HMAC-SHA256 signature verification and Replay Attack blocking.
- **📍 Real-Time GPS Tracking:** The live map utilizes the browser's `navigator.geolocation` API and Leaflet.js to track your real-time position on your route.
- **⚡ Hot-Reloading UX:** The frontend is built with React, Vite, and TailwindCSS for a seamless, SPA experience with no page reloads.

---

## 🏗️ Architecture & Tech Stack

### Frontend
- **Framework:** React 18 + Vite
- **Styling:** TailwindCSS + Lucide Icons + Framer Motion
- **State Management:** Zustand (Global) + LocalStorage Sync
- **Maps:** React Leaflet (`react-leaflet`)

### Backend
- **Server:** Node.js + Express
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Authentication:** HTTP-Only Cookies + JWT
- **AI Engine:** Google Cloud Dialogflow NLP
- **Payments:** Razorpay API

---

## 🛡️ Security Implementations

This project was built with a strong focus on enterprise-grade security:
1. **Offline QR Forgery Prevention:** Scanners run `jwt.verify()` using a secret key to ensure the QR code was generated by the backend and not tampered with.
2. **Replay Attack Mitigation:** Razorpay payment webhooks track processed `payment_ids` to ensure a hacker cannot replay the exact same successful payment request to double their balance.
3. **HTTP-Only Cookies:** Auth tokens are never exposed to `localStorage` or JavaScript, mitigating Cross-Site Scripting (XSS) attacks.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas cluster URL
- Razorpay API Keys
- Google Cloud Dialogflow Credentials

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/fare-wave.git
   cd fare-wave
   ```

2. **Install Backend Dependencies:**
   ```bash
   cd backend
   npm install
   ```

3. **Install Frontend Dependencies:**
   ```bash
   cd ../frontend
   npm install
   ```

### Environment Variables
Create a `.env` file in the `backend` directory:
```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_super_secret_jwt_key
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret
DIALOGFLOW_PROJECT_ID=your_dialogflow_project_id
```

### Run the App
From the root directory, start both the frontend and backend:
```bash
# Terminal 1 (Backend)
cd backend
npm run dev

# Terminal 2 (Frontend)
cd frontend
npm run dev
```
Open `http://localhost:5173` in your browser.
